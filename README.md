# Quiz ETL & OLAP

Site de estudo com questões objetivas e discursivas, dicas e correção comentada.

## Conteúdo

- Treino adaptativo com questões sobre ETL, Data Warehouse, OLAP, BI e modelagem multidimensional.
- Modo “Questões do material”: 25 exercícios dos PDFs de conteúdo e 11 itens do Banco de Questões.
- Questão 4 do Banco com o diagrama relacional fornecido e uma proposta de modelo estrela com consultas SQL.

## Executar

Abra `index.html` no navegador ou sirva esta pasta com um servidor HTTP estático. O projeto usa apenas HTML, CSS e JavaScript, sem instalação de dependências.

As respostas discursivas são autoavaliadas: compare sua resposta com os critérios e o exemplo apresentados após clicar em “Ver critérios”.
